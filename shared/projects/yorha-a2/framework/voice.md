# (d) 语气 / voice

> Framework v0 中 (d)。**从 subagent 那条文案逆向抽取的 voice 守护清单**。
> 上位：[YORHA-A2.md](../YORHA-A2.md) · 同伴：[concept-library.md](concept-library.md) / [scenario-library.md](scenario-library.md) / [story-shapes.md](story-shapes.md)

## 6 条 voice 规则

### 1. 口语，不端着

每句话**能用嘴说出来**，不是写出来的。

✅ "她决定和我分手的时候，我当然知道"  
❌ "面对感情结束这一现实，我意识到"

### 2. 自嘲 OK

承认自己不体面、自己看不起的样子，比正能量更打动人。

✅ "我开始一次次变成那个自己都看不起的样子"  
❌ "我学会了在感情中保持理性"

### 3. 中英技术词混用 OK

不刻意去翻译技术词。subagent / agent / fine-tune 直接出现，下沉读者**反而觉得带点专业感**。

✅ "一个叫感性的 subagent 告诉我：我不甘心"  
❌ "我内心一个感性的子智能体告诉我：我不甘心"

### 4. 短句节奏 + 段落留白

不写大段。每个 sub-thought 一段，1-3 行。让用户**能在抖音慢慢读**。

✅ 见原文格式：
```
理性叫你走。
感性叫你留。
自尊叫你别回头。
欲望叫你再靠近一点。
```

❌ "一方面理性告诉我应该离开，但另一方面感性又让我想留下..."

### 5. 不"AI 味"

避免：
- "在 X 的时代"
- "让我们一起"
- "赋能 / 助力 / 启迪"
- emoji 堆砌
- 排比句机械化
- "希望对你有帮助"结尾

### 6. punch line 要有"重量"，但不强加道理

结尾给的不是说教，是一个**新的解释**，让读者带走一个工具。

✅ "所谓成长，大概就是从被某一个 subagent 控制，慢慢变成自己这个主系统重新上线"  
❌ "总之，我们要学会管理好自己的情绪"

## 第一人称 vs 第二人称切换

subagent 那条混用了：

- 大部分时间 "我" 第一人称叙事（建立信任）
- 中段切 "你" 第二人称（让读者代入）：
  > "但这时候，又会有一个叫自尊的 subagent 拦住我。"
  → "理性叫你走。感性叫你留。"

切换的逻辑：**讲自己的具体故事用"我"，归纳普世经验用"你"**。读者从"听他讲" 转到 "对，我也是"。

## 单词 / 表达样本（白名单）

从 subagent 那条提取的高频 / 标志性表达，可以重复使用建立账号语言识别度：

- "subagent" / "agent" / "主系统"
- "不甘心"
- "体面"
- "自己都看不起的样子"
- "假装" / "其实"
- "拦住我" / "告诉我"
- "再多说一句，她就会回头"

## 单词 / 表达样本（黑名单）

不要出现：

- "宝子们" / "家人们"
- "干货" / "硬核"
- "彻底改变了我"
- "码住" / "建议收藏"
- "AI 时代来了"
- "上车不亏" / "破防了"（除非反讽用）

不是这些词本身不好，是它们**跟 YoRHa-A2 的"内省 + 跨界"调性冲突**。其它账号可以用，本号不用。

## review 文案时按这套校准

每写一条 draft 检查：

- [ ] 念出声是否别扭？（违反规则 1）
- [ ] 有没有粉饰 / 美化自己？（违反规则 2）
- [ ] 技术词有没有过度翻译？（违反规则 3）
- [ ] 段落是否过长？（违反规则 4）
- [ ] 有没有"AI 味"短语？（违反规则 5）
- [ ] punch line 是给工具还是给道理？（违反规则 6）
- [ ] 第一人称 / 第二人称切换合理？
- [ ] 用了白名单的标志性表达建立识别度？
- [ ] 没用黑名单的词？
