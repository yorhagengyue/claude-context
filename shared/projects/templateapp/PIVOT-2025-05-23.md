## What the paper says (interpretation)

Title: **Agentic AI for Generic Document Generation with Live-Data Binding and LLM Evaluator**

Problem statement (paper Introduction):
- Knowledge workers spend ≈28% of work week on docs; ≈2.5 h/day on doc handling
- 40% error rate in manual doc processing → 3-day average approval lag
- Enterprises lose $85k–$250k/year on compliance costs from inconsistent docs
- 29 AI tools surveyed in Annex 1 (Table 2): NONE simultaneously offers
  1. **Live Data Binding** (doc reflects current data, not snapshot)
  2. **LLM-as-a-Judge** (automated quality gate before delivery)

Proposed solution: **agentic framework** with these agents (Figure 1):
- Orchestrator (coordinates)
- Dataset agent (fetch & create)
- Loader agent (load & transform)
- Template agent (build template)
- Report writer (generate output)
- LLM judge agent (validate: Accuracy / Completeness / Clarity / Data consistency / Format compliance) → Pass=Final, Fail=feedback to Writer

## Why this is a real pivot

It's not just a re-skin. The original Phase 1 plan (`~/.claude/plans/shimmying-dreaming-naur.md`) was a generic document generator with these primary surfaces:
- ONLYOFFICE-based template authoring
- docxtpl-rendered generation
- A Review module as an afterthought

The agentic re-framing forces:
- **Backend rewrite as Python agent pipeline** (no more Node-only CRUD)
- **LLM-as-Judge becomes central**, not afterthought
- **Live data binding is a new mechanism** requiring version-graph dependency tracking
- **Paper deliverable** means actual research effort: literature review, empirical comparison, methodology, results

Timing observation: backend hadn't been written yet on 5/23 (`api/` is just a README, `services/` are empty dirs). Frontend was scaffolded but minimally backed. **No code thrown away by the pivot** — the existing 9 frontend pages map 1:1 to the Figure 1 agents:

| Figure 1 agent | Existing frontend surface |
|---|---|
| Dataset | `/datasets` |
| Loader | (backend logic) |
| Template | `/templates`, `/templates/edit` |
| Report Writer | `/runs` (Generate Wizard) |
| LLM Judge | `/review` |
| Orchestrator | (backend logic) + new `/runs` → Agent Timeline view |
