LAYER 01

Ingestion

Source-agnostic. Every connector writes into the same canonical schema, so adding a blood-pressure cuff or smart scale is a recipe, not a redesign.

Today: Apple Watch via HAE + Discord presence via Lanyard. Tomorrow: any HTTPS-capable device.

LAYER 02

Processing

Two parallel planes on the same Workato platform. Data plane is deterministic (curate · baseline · store). Reasoning plane is LLM-touched (rules · disambiguation · multi-agent chain).

Both converge into one MCP server. Pattern D · RAG. No model training before pitch. Rule confidence cited to peer-reviewed evidence.

LAYER 03

Communication

Dual surface. AI clients consume tools through MCP. Humans receive nudges in their own channel — WhatsApp, WeChat, Telegram, family circle.

Thumbs up / down on every output flows back as RLHF signal into the rule evaluator — closing the data flywheel.
